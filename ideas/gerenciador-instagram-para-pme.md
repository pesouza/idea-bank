
# Gerenciador de Instagram para PMEs via API

- **resumo**: Uma ferramenta para que PMEs possam agendar posts, responder DMs e monitorar métricas do Instagram a partir de uma interface centralizada, integrada ao ecossistema da Aeria.
- **problema que resolve**: Pequenos e médios empresários não têm tempo para gerenciar o Instagram eficientemente. Ferramentas existentes são caras ou complexas demais. Falta uma solução integrada que conecte o marketing de redes sociais com outras operações do negócio (CRM, vendas).
- **viabilidade**: 
- **Técnica (Média):** A integração depende da API da Meta, que é bem documentada mas pode ter um processo de aprovação rigoroso. O desenvolvimento do backend para agendamento e o frontend do dashboard são relativamente simples.
- **Mercado (Alta):** Existe uma demanda enorme por automação de redes sociais por parte de PMEs. O desafio é a diferenciação e o custo de aquisição de clientes.
- **Custo (Baixo/Médio):** Custo inicial focado em desenvolvimento. Custos recorrentes com servidores e manutenção da API.

- **prós / contras**: 
**Prós:**
- Grande mercado potencial.
- Modelo de negócio SaaS com receita recorrente.
- Sinergia clara com a oferta atual de Selfware da Aeria.
- Resolve um problema real e doloroso para PMEs.

**Contras:**
- Mercado competitivo com players grandes (mLabs, Etus, etc.).
- Dependência total da API e das políticas da Meta/Instagram.
- Necessidade de um bom suporte ao cliente.
- Requer um esforço de marketing significativo para se destacar.

- **MVP**: 
1. **Autenticação Segura:** Permitir que o usuário conecte sua conta do Instagram (Business/Creator) de forma segura via OAuth.
2. **Agendamento de Posts:** Funcionalidade para agendar a publicação de uma imagem com legenda em uma data/hora futura.
3. **Dashboard Simples:** Uma tela para ver os posts agendados.

- **sinergias**: 
- **Aeria Selfware:** Pode ser um módulo adicional ou um novo produto dentro do portfólio de automação da Aeria, oferecido para a mesma base de clientes PME.
- **Aeria CRM:** Integração para que as interações no Instagram (DMs, comentários) possam se tornar leads ou tickets de suporte no CRM.
- **aeria-apps.com.br:** O site pode servir como plataforma de marketing e vendas para essa nova ferramenta.

- **próximos passos**: 
1. **Pesquisa de API:** Investigar a documentação da API Graph do Instagram para detalhar os requisitos técnicos e limitações.
2. **Análise de Concorrência:** Mapear os principais concorrentes (mLabs, Etus) para identificar funcionalidades essenciais e oportunidades de diferenciação.
3. **Protótipo de Baixa Fidelidade:** Desenhar as telas principais do MVP.
